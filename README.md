# Task Tracker Application

## Overview
This is a simple Task Tracker web application developed using React and Spring Boot.

Users can:
- View tasks
- Add tasks
- Mark tasks as completed
- Delete tasks

---

## Tech Stack

### Frontend
- React JS
- CSS

### Backend
- Spring Boot
- Java

### Database
- H2 Database

### Version Control
- Git & GitHub

---

## Features
- Add new tasks
- View all tasks
- Mark tasks as complete
- Delete tasks
- Responsive modern UI
